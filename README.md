# 仙途行囊

修仙主题的每日任务与习惯修行管理工具。支持手机、电脑多端使用；部署后可**安装到手机桌面、全屏打开、离线可用**（PWA）。

## ✨ 功能一览

| 模块 | 说明 |
|---|---|
| 每日十课 | 竖式书架管理每日修行卷轴，按「日期 + 当日卷号」编号，同一书架按时间倒序排列，支持多卷、未完成顺延；完成任务获得**晶核** |
| 行迹 | 完成任务自动留下**永久修行记录**，按实际完成顺序编号，可搜索 / 按标签筛选 / 统计 |
| 任务标签 | 每个任务可打多个自定义标签（可增删改），用于分类、筛选、搜索、统计 |
| 卷轴封卷 | 每天 00:00 后当天卷轴自动🔒封卷，仅可查看；解封需二次确认（切忌自我欺骗），解封后亦可重新封印 |
| 物品行囊 | 记录收集的修行物品与数量，支持在线图片 URL / 本地上传图片 / 默认图标 |
| 万宝阁 | 用晶核兑换奖励的修行商店，商品完全自定义 |
| 晶核 / 灵气 | 完成现实任务赚晶核（◇）；晶核可购买商品，也可吸收为灵气（1:100，✦） |
| 被动功法 | 沉淀已养成的好习惯 |
| 走火入魔录 | 记录失败尝试与原因 |
| 悟道札记 | 保存值得反复使用的心得 |
| 数据同步 | 可选接入 Firebase / Supabase / Notion 多端同步（含晶核 / 灵气 / 商品 / 流水 / 行迹） |

## ✨ 核心：卷轴 → 严格完成 → 行迹留痕 → 资源奖励

```
📚 每日十课 → 创建每日卷轴 → 9.2 卷2 · 任务 → [待修行]
     ↓ 完成
┌─────┼─────┬──────────┐
行迹   晶核+1   完成时间
9.2卷2-1 9.2卷2-2 9.2卷2-3   （按实际完成顺序编号）
     ↓
永久修行记录        每日 00:00 → 🔒 封卷
                        ↓
             查看 / 解封 → 二次确认 → 编辑
             解封后亦可 → 🔒 重新封印
```

### 📖 卷轴书架

- 所有「每日十课」卷轴**不区分日期，全部在同一书架**，按**时间倒序**排列：最新日期的卷轴排最前，同日按卷号正序，例如 `9.2卷1、9.2卷2、9.1卷1`
- 卷轴编号 = 「日期 + 当日卷号」，如 `9.2 卷1`、`9.2 卷2`
- 以每天 **00:00** 为界：当天卷轴可编辑 / 可完成任务；过期卷轴自动🔒封卷，可展开查看历史内容
- 封卷卷轴显示「🔒 已封卷」+「解封」按钮；点击解封需**二次确认**：*是否解封此卷轴？切忌自我欺骗*；确认后恢复全部编辑权限
- 解封后的卷轴可随时**「🔒 重新封印」**（同样二次确认），封印后恢复锁定状态，仅可查看

### 🏷 任务标签

- 每个任务可拥有**多个标签**（如 `[英语] [学习] [长期]`），标签非必填
- 标签可自行创建、修改、删除（编辑任务时输入新标签回车，或点选常用标签）
- 每日十课与行迹页均支持**按标签筛选**；行迹页支持**搜索**与**标签统计**

### 🧭 行迹（永久完成记录）

- 任务完成后**自动进入行迹**，保留：原始卷轴编号、任务名称、标签、完成时间、完成顺序、行迹编号
- 行迹编号按**实际完成顺序**（而非原任务顺序），如 `9.2 卷2-1 阅读 / 9.2 卷2-2 英语 / 9.2 卷2-3 整理房间`
- 行迹属于**历史档案**：修改每日十课的任务（改名、加标签、删除卷轴）都不会丢失行迹

### ⭕ 严格完成交互

- 任务**唯一**完成入口是「待修行」按钮：点击 → 任务完成 → 进入行迹 → 晶核 +1
- 点击任务名称 / 标签 / 卡片 / 空白区域 / 展开收起，均**不会**完成任务，最大限度避免误触
- 完成浮窗 2 秒内可「撤回」（任务恢复 + 晶核 -1 + 移除行迹）；已完成任务可在详情中「取消完成」（二次确认）

1. 用手机 **Chrome 或系统自带浏览器** 打开上面的网址

## 💻 电脑使用

电脑浏览器直接打开网址即可，所有功能与手机一致。数据存在浏览器本地；多端数据互通需配置云同步。

## 🔄 更新页面内容

- **小改动**：仓库里点 `index.html` → 右上角铅笔图标编辑 → 页面底部 **Commit changes**
- **大改动**：**Add file → Upload files** 上传同名文件自动覆盖 → 务必点「Commit changes」
- **⚠️ 必做**：每次更新同步修改 `sw.js` 的版本号（`xiantu-v2` → `xiantu-v3` → `xiantu-v4` → v5…），否则手机端可能显示旧版
- 更新后等 1–3 分钟部署完成，重新打开即是新版

## ❓ 常见问题

**Q：部署后点图标还是打开浏览器？** 确认网址是 `https://` 开头。PWA 只支持 https（或 localhost）。

**Q：手机上还是旧版？** 先检查 `sw.js` 版本号是否已 +1；仍旧就完全关闭页面再重新打开一次。

**Q：上传文件后线上没变化？** 上传后一定要点页面底部的「Commit changes」，并确认仓库里 `index.html` 大小约 119KB（v4 新版）；上传成功后等 1–3 分钟 GitHub Pages 发布。

**Q：离线能用吗？** 可以。主页面与图标已做离线缓存；云端同步功能需联网。

**Q：想手机和电脑数据互通？** 在「修行设置 → 高级设置」里配置 Firebase 或 Supabase 云同步，同一账号登录后多端自动同步。
