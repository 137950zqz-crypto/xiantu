# 仙途行囊

修仙主题的每日任务与习惯修行管理工具。支持手机、电脑多端使用；部署后可**安装到手机桌面、全屏打开、离线可用**（PWA）。

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| 每日十课 | 书架式管理每日修行任务，支持多卷、未完成顺延；完成任务可获得**晶核** |
| 物品行囊 | 记录收集的修行物品与数量，万宝阁购买的商品也存入此处 |
| 万宝阁 | 用晶核兑换奖励的修行商店，商品完全自定义 |
| 晶核 / 灵气 | 完成现实任务赚晶核；晶核可购买商品，也可吸收为灵气（1:100） |
| 被动功法 | 沉淀已养成的好习惯 |
| 走火入魔录 | 记录失败尝试与原因 |
| 悟道札记 | 保存值得反复使用的心得 |
| 数据同步 | 可选接入 Firebase / Supabase / Notion 多端同步（含晶核 / 灵气 / 商品 / 流水） |

## ✨ v2 新增：晶核 + 万宝阁（修行经济系统）

> 核心理念：**现实中的行动 → 产生游戏资源 → 兑换现实中的奖励**。「每日十课」是资源生产器，「万宝阁」是资源消费器，「行囊」是奖励管理器。

### 💎 每日十课 · 完成任务获得晶核
- 完成 1 课 → **晶核 +1**
- 弹出半透明浮窗「◆ 获得晶核 ×1」，约 2 秒自动消失
- 浮窗带「**撤回**」按钮：2 秒内点击可撤回（任务恢复未完成 + 晶核 -1，防止误触）
- 再次点击已完成任务 = 取消完成 → 晶核 -1，并提示

### 🏪 万宝阁（侧边栏 + 手机底部导航可进入）
- 顶部显示**晶核余额**与**灵气**，右侧「吸收晶核」按钮
- 商品完全**用户自定义**：「＋新增商品」可设置名称 / 描述 / 价格 / 图标 / 类型（实物·娱乐·休息·其他）
- 商品卡片点「⋯」可**编辑 / 删除**
- 购买分两种：
  - **购买并放入行囊** → 晶核扣除，商品进入物品行囊
  - **购买并使用** → 晶核扣除，商品进入行囊并标记「已使用」
- 晶核不足时提示「晶核不足」，不扣款

### ✦ 吸收晶核 → 灵气
- **1 晶核 = 100 灵气**（第一版支持吸收 1 枚）
- 灵气为成长储备资源，与晶核（货币）严格区分

### 🧾 晶核流水（交易记录）
- 万宝阁「流水」按钮可查看全部记录
- 记录类型：`完成一课 +1` / `购买 -N` / `撤回` / `取消完成` / `吸收晶核`
- 每条含时间、事项、数量，方便追溯「晶核去哪了」

## 🔄 更新页面内容

网址**长期有效**，更新只需覆盖文件，网址和已安装的图标都不变。

- **小改动**：仓库里点 `index.html` → 右上角铅笔图标编辑 → 页面底部 **Commit changes**
- **大改动**：**Add file → Upload files** 上传同名文件，自动覆盖旧文件 → **务必点页面底部绿色「Commit changes」按钮**，否则不会保存
- **⚠️ 必做**：每次更新同步修改 `sw.js` 第 5 行的版本号（`xiantu-v1` → `v2` → `v3`…），否则手机端可能显示旧版
- 更新后等 1–3 分钟部署完成，重新打开即是新版

## ❓ 常见问题

**Q：部署后点图标还是打开浏览器？**
确认网址是 `https://` 开头。PWA 只支持 https（或 localhost），本地双击 file:// 无效。

**Q：手机上还是旧版？**
先检查 `sw.js` 版本号是否已 +1；仍旧就完全关闭页面再重新打开一次。

**Q：上传文件后线上没变化？**
上传后一定要点页面底部的「Commit changes」，并确认仓库里 `index.html` 大小约 97KB（新版）；上传成功后等 1–3 分钟 GitHub Pages 发布。

**Q：离线能用吗？**
可以。主页面与图标已做离线缓存；云端同步功能需联网。

**Q：想手机和电脑数据互通？**
在「修行设置 → 高级设置」里配置 Firebase 或 Supabase 云同步，同一账号登录后多端自动同步。
