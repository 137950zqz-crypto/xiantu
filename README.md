# 仙途行囊

修仙主题的每日任务与习惯修行管理工具。支持手机、电脑多端使用；部署后可**安装到手机桌面、全屏打开、离线可用**（PWA）。

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| 每日十课 | 书架式管理每日修行任务，支持多卷、未完成顺延 |
| 物品行囊 | 记录收集的修行物品与数量 |
| 被动功法 | 沉淀已养成的好习惯 |
| 走火入魔录 | 记录失败尝试与原因 |
| 悟道札记 | 保存值得反复使用的心得 |
| 数据同步 | 可选接入 Firebase / Supabase / Notion 多端同步 |

## 🌐 在线访问

- 网址：`https://137950zqz-crypto.github.io/xiantu/`
- 首次部署：仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main`，文件夹选 `/(root)`，点 Save，等 1–3 分钟生效

## 📱 手机安装（像 App 一样全屏打开）

1. 用手机 **Chrome 或系统自带浏览器** 打开上面的网址
2. 点右上角菜单 **⋮** → **「添加到主屏幕」**（或「安装应用」）
3. 回到桌面，点击「仙途行囊」图标即可全屏使用，不再经过浏览器首页

> 注意：必须是 **https** 网址；建议用 Chrome 或系统浏览器（部分国产三方浏览器不支持）。

## 💻 电脑使用

电脑浏览器直接打开网址即可，所有功能与手机一致。数据存在浏览器本地；多端数据互通需配置云同步（见「数据同步」）。

## 🔄 更新页面内容

网址**长期有效**，更新只需覆盖文件，网址和已安装的图标都不变。

- **小改动**：仓库里点 `index.html` → 右上角铅笔图标编辑 → 页面底部 **Commit changes**
- **大改动**：**Add file → Upload files** 上传同名文件，自动覆盖旧文件 → Commit changes
- **⚠️ 必做**：每次更新同步修改 `sw.js` 第 5 行的版本号（`xiantu-v1` → `v2` → `v3`…），否则手机端可能显示旧版
- 更新后等 1–3 分钟部署完成，重新打开即是新版

## ❓ 常见问题

**Q：部署后点图标还是打开浏览器？**
确认网址是 `https://` 开头。PWA 只支持 https（或 localhost），本地双击 file:// 无效。

**Q：手机上还是旧版？**
先检查 `sw.js` 版本号是否已 +1；仍旧就完全关闭页面再重新打开一次。

**Q：离线能用吗？**
可以。主页面与图标已做离线缓存；云端同步功能需联网。

**Q：想手机和电脑数据互通？**
在「修行设置 → 高级设置」里配置 Firebase 或 Supabase 云同步，同一账号登录后多端自动同步。
